# The rich editor

<AddonHeader />

A markdown field opens as a real editor in the page: same heading, same measure, same font,
now with a cursor in it. It is on by default, and it has a cost that is worth stating before
the features.

## It is Tiptap, and that is not incidental

**Statamic's own Bard is built on Tiptap.** The shortcuts, the selection behaviour and the way
a list continues on Enter are the ones a client already met in the control panel, which is the
argument for using it rather than writing something smaller.

| What you type | What happens |
| --- | --- |
| `## ` | heading, level two |
| `### ` | heading, level three |
| `- ` | bullet list |
| `> ` | quote |
| `**bold**` | bold, as the second pair of asterisks closes |
| `*italic*` | italic |
| `---` | horizontal rule |

Selecting text raises a small toolbar with bold, italic, the two heading levels, list, quote
and link. Light, with icons, the way Bard's is.

It goes in the page's margin where the page has one, because a toolbar over a line of text
always hides something and a reading measure usually leaves room beside it. Only when there is
no margin, on a phone, does it go over the text, and then above the selection.

## What it costs

A rich editor reads markdown into a document and writes the document back out. **Markdown has
more than one spelling for the same document.**

| Stored | May come back as |
| --- | --- |
| `*emphasis*` | `_emphasis_` |
| a setext heading, underlined with `===` | `# a setext heading` |
| a reference link, `[text][ref]` | an inline link, `[text](url)` |
| `+ item` | `- item` |

Editing one sentence therefore rewrites the whole field in the editor's dialect. The rendered
page is identical; the file is not.

::: warning The one thing that never happens
Opening a field and closing it without typing never writes anything. The comparison is against
what the editor produced when it mounted, not against what was stored, so a pure normalisation
is not a change and does not arm the save button.
:::

## When to switch it off

Set `rich` to `false` and a markdown field opens as its own source in a monospace box instead.
Do that if the markdown has to come back byte for byte:

- hand-written tables, where the column padding is deliberate
- raw HTML blocks inside the markdown
- footnotes, definition lists, or anything else an extension added
- content generated by something else that will read it back

```php
// config/statamic-inline-edit.php
'rich' => false,
```

It is a per-site switch, not per-field. A site that has one such field probably has several,
and a rule that sometimes applies is a rule nobody can predict.

## What it weighs

| | |
| --- | --- |
| On every page an editor opens | 12 KB of JavaScript and 8 KB of CSS, gzipped |
| The first time a markdown field is opened | 179 KB, gzipped, once, then cached |
| On a page nobody is editing | nothing |
| For a visitor | nothing |

The rich editor is a separate file, fetched on demand. A site whose editors only ever fix
headlines never downloads it.

::: tip This is the addon's only build step
`resources/dist/inline-edit-rich.js` is committed, because a site installing the addon gets no
build. A CI job rebuilds it from source and fails on a diff, so the file in the repository is
always the file the source produces.
:::

## Links

The link button asks for the address with the browser's own prompt, and pressing it again on
an existing link removes it.

Deliberately the browser's box rather than a dialog of our own: it is one string, the browser's
box is reachable by keyboard and screen reader for free, and a hand-built modal inside a
client's page is a second thing to keep working in somebody else's CSS.

## Writing after a list

Press Enter twice at the end of the last item.

ProseMirror normally appends an empty paragraph to a document that ends with a list, so there
is somewhere to type. That paragraph is content the document does not have, and it made the
block 36 pixels taller the moment the editor mounted, pushing the rest of the page down and
pulling it back up on close. It is switched off. The cost is this one keystroke.
